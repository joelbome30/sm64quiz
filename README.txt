La nueva versión cambia la composición para parecerse más al File Select real de SM64:
- marco amarillo/bevel alrededor de la pantalla
- respuestas con el cuadro de archivo a la izquierda y texto a la derecha
- tipografía manuscrita para el menú en vez de una fuente pixel genérica
- título multicolor con volumen
- botones inferiores como SCORE/COPY/ERASE
- mantiene el cursor de la mano

Los archivos usan Google Fonts (Titan One y Patrick Hand SC). Si no hay conexión, el navegador usará fuentes de respaldo.
